# NAV2 生产形态观测轮简报（round 3a，无注入）

> 云端 amr_nav2_sim（4C/4G 限额）· nav2_localized · 2026-09-08 起
> 性质：P2 后半首个 NAV2 全栈长时观测（前两轮 72h soak 均为已退役旧管线）

## 已采集（v3 修复后）

- **导航成功率 60/60 腿（15 循环），零超时**
- 循环时距 45.0~52.7s（四站巡回，含站间冷却）
- 控制环零降频告警（10Hz 配置下）
- RSS 全稳定：9 进程首末采样对比零增长（guard 33-34MB / planner 58-60 /
  bt_nav 73 / foxglove 75 / map_server 46-47 / behavior 47-48 / amcl 47-48 /
  controller 56-59 / scene 37-38）——**NAV2 生产形态内存足迹 ~460MB（不含
  foxglove ~385MB），无泄漏迹象**

## 两个发现（已修复闭环）

1. **贴货架角瞬时拒绝死循环**：绕角停车于膨胀带内（距障碍 0.38m）→
   后续目标 20ms 根失败循环，**恢复行为零执行**（ClearCostmap/Spin/BackUp
   计数全零）。开放项：恢复分支为何未触发——复现时录 /behavior_tree_log
   + 隔离测 Smac 起点带代价行为（finding1_*.log 已存档）
2. **停滞-重发-负载正反馈**：控制环 20→7.7Hz（弱算力）→ F1 契约速度
   间歇清零 → 进度判停 → runner 无节流重发（10Hz 目标洪水）→ 负载恶化。
   修复：runner 节流 15s（c4013de）+ controller_frequency 10Hz 入库
